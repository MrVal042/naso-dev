# Benchmarks: what an agent loads at session start

Every token in `AGENTS.md`, `CLAUDE.md` and the files they import is read at the start of
every session, before the agent does any work. This page is the baseline every change to
what NASO writes is measured against. A change that makes the briefing longer has to say
what it buys; a change that makes it shorter has to show the number went down.

## Method

- `npx naso-dev stats <repo> --json`, which counts CLAUDE.md and every file it imports,
  AGENTS.md, and the NOW section of the handoff, each file once.
- Tokens are characters divided by four, rounded up. No tokenizer: the same number on every
  machine, wrong by about the same factor for every file, which is what a before/after
  comparison needs. Real tokenizers give a different absolute number; the ratios hold.
- Each public repository was cloned with `--depth 50` at the commit below, and set up with
  NASO 1.5.4: `npx naso-dev@1.5.4 <repo> --yes --no-hook`. That writes `AGENTS.md` and a
  one-line `CLAUDE.md` link and needs no network.
- "As cloned" is what the repository itself shipped for agents before NASO. None of the
  seven sample repositories shipped an AGENTS.md or a CLAUDE.md.
- The field repository is a private application this tool is used on daily. It is not
  named. It was measured twice: as generated by 1.5.4 in a scratch clone, and as it is
  committed after people and the `review` prompt corrected the block.

## Largest sections

As generated, the same two sections lead almost every repository, and they say nearly the
same thing everywhere:

| Section | Tokens, every sample | Share of the median load |
| --- | ---: | ---: |
| Decisions | 284–288 | 17% |
| Scope | 224–226 | 13% |
| CLAUDE.md link | 34 | 2% |

The rest is the per-repository content: the title paragraph (173–378), Project Structure
(200–270), Commit Standard (about 170–205), and in gson a Merge Request Checklist (290).

As reviewed, the field repository's largest sections are Commands (815), Stack Rules (780),
Project Structure (436), Decisions (302) and Deploy and CI (293).

## What this means for the later phases

- About 540 tokens of every generated load (Decisions, Scope, the CLAUDE.md link) is the
  same text in every repository. That is the first thing to move into a file read on
  demand.
- Generation is not where the size comes from in practice. The review step roughly triples
  the block, mostly by adding commands, stack rules and project structure an agent needs.
  The layered layout has to give that added detail somewhere to go other than the root
  block, or the root grows back after every review.
- No sample repository shipped any agent file, so for most teams NASO's load is the whole
  load. It should stay well under the reviewed field size.

## Reproduce

```bash
git clone --depth 50 https://github.com/spf13/cobra.git && cd cobra
npx naso-dev@1.5.4 . --yes --no-hook
npx naso-dev stats . --json
```

Each later phase adds its own row set below, with the same repositories at the same
commits, and the change against this baseline.

## Phase 1: handoff and Read First (1.6.0, unreleased)

Setup now writes a handoff and puts a Read First section at the top of the block. Same
repositories, same commits, `--force` to regenerate. Setup kept every handoff local, so it is
`.git/naso/HANDOFF.md`, and its NOW section is empty until somebody sets it.

| Repository | Baseline | Phase 1 | Change | Read First | Handoff NOW, empty |
| --- | ---: | ---: | ---: | ---: | ---: |
| changesets/changesets | 1,911 | 2,026 | +115 | 115 | 1 |
| psf/requests | 1,490 | 1,602 | +112 | 111 | 1 |
| spf13/cobra | 1,506 | 1,618 | +112 | 111 | 1 |
| BurntSushi/ripgrep | 1,701 | 1,813 | +112 | 111 | 1 |
| google/gson | 1,696 | 1,808 | +112 | 111 | 1 |
| terraform-aws-modules/terraform-aws-vpc | 1,314 | 1,426 | +112 | 111 | 1 |
| naso-dev | 1,670 | 1,782 | +112 | 111 | 1 |
| field repository, as generated | 1,576 | 1,691 | +115 | 114 | 1 |

Median 1,670 → 1,782 (+6.7%). Read First names both handoff commands (`set` for NOW, `log`
for history) and what NOW holds, because the handoff's own explanation is not loaded at
session start and NOW is.

A realistic NOW, a state paragraph, two next steps and two open items, is 65 tokens
(cobra: 1,618 → 1,682). NOW is replaced, not added to, so it stays that size however many
sessions update it; only the log grows, and the log is not loaded. At its 60-line cap NOW
would be about 600–900 tokens, and the gate warns before that. Phase 4 has to win the Read
First cost back.

## Phase 2: rules that are easy to get wrong, and lessons (1.6.0, unreleased)

Read First gains one line about lessons (+30 tokens). The rules section appears only where
the repository has a source for it. The branch pattern, CONTRIBUTING's merge rules and the
CODEOWNERS line moved into it from Commit Standard and Boundaries, so each is said once.

Median 1,670 → 1,812 (+8.5%). requests gained its rules section and still grew by only 33
tokens from Phase 1, because the CODEOWNERS line left Boundaries. The field repository has
48 accepted decisions. Only those whose decision states a constraint (never, always, must,
only, do not, instead of, rather than, should not) are rules: 17 of the 48, and none of them
a price or a plan. Four of those, cut to one sentence each, are most of its 394 tokens, which
is the section's ceiling in practice.

Every row has an empty NOW. (The cobra clone still held the 65-token sample NOW from
Phase 1; it is left out here so the rows compare like for like.)

## Phase 3: Claude Code extras (1.6.0, unreleased)

Every extra is opt-in, so a default setup loads exactly what Phase 2 loads: naso-dev stays at
1,812. With them turned on (naso-dev, same commit):

| What | Tokens at session start |
| --- | ---: |
| Default setup, no extras | 1,812 |
| `--skills`: four skill descriptions (naso-decide 52, naso-handoff 53, naso-pre-pr 42, naso-sweep 42) | +189 |
| `--hooks`: the SessionStart output beyond the NOW section already counted (a header and one line about the briefing) | about +25 |
| `--deny` | 0: deny rules are settings, not context |

`stats` now counts each skill's front matter. The hook output is not a file, so it is
estimated from its length (102 characters with an empty NOW).

## Phase 4: the layered block (2.0.0, unreleased)

The block keeps what every session needs and routes the rest, through a When You Touch
table, to guides in `.naso/guides/` that load only when a task needs one. Area lines lost
their file counts and the root-file list is gone. Same repositories, same commits, regenerated
with `--force`. "Guides" is what the guides would cost if all of them were read; nothing reads
them at session start.

Median of the seven samples: 1,670 → **849** (−49%), against 1,812 at Phase 2. "Block lines" is
every line between the markers, and in brackets the lines of text, without blank lines and HTML
comments; `briefing` gives a notice past 60 of those, and no sample is near it.

- **cobra** is measured with an empty NOW, as at Phase 2: the clone still holds the 65-token
  sample NOW from Phase 1, so the 823 that `stats` prints there is 759 plus that sample.
- **changesets** keeps the largest block because of its rules section (CODEOWNERS) and its
  validation commands, both of which every session needs.
- **The reviewed field briefing** is the committed `AGENTS.md` of the field repository,
  migrated in a scratch clone. Every section moved word for word; what stays at session start
  is what its reviewers wrote about the areas, the secrets and when work is done. It predates
  1.6.0, so it has no Read First or rules section yet; adding them is review's job. The 3,590
  tokens moved into guides are read when a task
  needs them: 2,178 of them are conventions and commands, 740 workflow, 372 decisions and 300
  the source map of `apps/`.
- **Reading a guide costs what it did before** when the task needs it. A session that commits
  reads `workflow.md` (417–700 tokens as generated here, 740 in the reviewed field repository;
  gson's includes its merge request checklist); one that only reads code never does. The
  decisions guide is 362–369 tokens everywhere, the fixed text the baseline found in every
  sample.
