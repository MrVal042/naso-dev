# field-notes — Conventions

Read this when you write or change code. The NASO block in `AGENTS.md` links it, and `npx naso-dev briefing` checks it with the block. Edit it like the block: say which file proves a correction.

## Stack Rules

- Every file under `app/` is a route (Expo Router). Components, hooks and helpers live outside it.
- ios/ and android/ are generated by `npx expo prebuild` and ignored (`.gitignore`). Change native settings in `app.json`, never in those folders.
- Add native packages with `npx expo install <name>`, which picks the version this Expo SDK supports.
- Anything in an `EXPO_PUBLIC_` variable is compiled into the app and readable by whoever has it; never put a secret there.

## Code Conventions

Package manager: npm (from package-lock.json). Every command in this file uses it.
Modules: .js files are CommonJS (no "type": "module"); TypeScript source is compiled by its toolchain and uses import syntax whatever this says.
TypeScript ~5.3.3 (package.json range), tsconfig.json present, "strict": true.
Tests: runner jest, 1 test file co-located with the source they test, `npm run test` names no path, so it discovers its own inputs.
Jest (`package.json` "jest"): preset `jest-expo`.
Import aliases: @ → the repository root (tsconfig.json as @/*).

## Boundaries

**Generated by the framework.** `.expo/` is written by Expo (`npx expo start` or `npx expo customize tsconfig.json`) and git-ignored: never edit or commit it. Type-checking does not read them.
